# Technology Stack

## Why Go for Orchestrator + Agent
- Native K8s ecosystem (client-go)
- Small binaries, fast startup
- Excellent gRPC support
- Concurrency with goroutines

## Why Python for AI Engine
- ML ecosystem (scikit-learn, XGBoost, PyTorch)
- FastAPI for async APIs
- PuLP for linear programming
- Rapid model iteration

## Why Next.js for Dashboard
- App Router for server components
- TypeScript end-to-end
- Tailwind for rapid UI
- Vercel deployment ready

## Why NATS JetStream
- Native async messaging
- Persistence for replay
- Lightweight, K8s-native

## Why TimescaleDB
- PostgreSQL-compatible
- Time-series hypertables
- SQL interface for metrics
