# Pricing

## Free
- Up to 20 nodes
- 100 task credits/month
- GitHub + Google auth
- Community support

## Pro — $49/cluster/month
- Unlimited nodes
- 1000 task credits/month per cluster
- SSO (SAML)
- Email support
- 99.9% SLA

## Enterprise — Custom
- Unlimited clusters
- Custom task credits
- BYOM (bring your own model)
- Self-hosted option (v2)
- Dedicated support
- SOC 2 Type II

## Task Credits
- 1 credit = 1 routing decision applied
- Unused credits roll over 1 month
- Top-up available in Pro
